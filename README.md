# GdSiecle – Grand Siècle

> Application TEI Publisher dédiée à l'exploration des discours français sur la peinture du premier XVIIe siècle. Elle donne accès à un corpus de plusieurs centaines de sources anciennes — écrits d'artistes, d'amateurs et de curieux — éditées, commentées et interrogeables par mots-clefs. Cet outil s'inscrit dans un projet de recherche visant à retracer la naissance d'un langage artistique proprement français, entre la fin du XVIe siècle et les années 1650.
